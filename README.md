# 騎樓沒有路 NO WAY THROUGH

像素風手機網頁遊戲——體驗輪椅族與視障者在台灣街道通勤的日常障礙。

- 單一檔案（`index.html`），純 HTML/CSS/JS，無框架、無外部圖片資源
- 字體：Google Fonts「Press Start 2P」＋「Noto Sans TC」
- 存檔：瀏覽器 localStorage（key `wcgame:save`）
- 設計規格見 `DESIGN_HANDOFF.md`

## 部署

GitHub Pages（main 分支根目錄）。更新方式：修改 `index.html` 後 commit 並推上 GitHub，Pages 會自動重新發布。
